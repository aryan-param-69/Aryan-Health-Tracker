# 🏥 Aryan Health Tracker

**Aryan Health Tracker** is a premium wellness monitoring application designed to simplify health data tracking. Featuring a modern "Glassmorphic" aesthetic, it provides users with an intuitive interface to visualize their vitals, daily activity, and long-term health goals.

---

## 🌟 Key Features
* **Interactive Health Dashboard:** Visualizes steps, sleep, and caloric burn using high-performance React charts.
* **Vitals Monitoring:** Real-time tracking of Heart Rate and Activity levels.
* **Modern UI/UX:** A sleek, translucent design system optimized for readability and user engagement.
* **Cross-Platform Ready:** Fully responsive design that works seamlessly on desktop, tablet, and mobile.

## 🛠️ Technical Stack
* **Frontend:** React.js + Vite (for lightning-fast development)
* **Styling:** Tailwind CSS (Glassmorphism & Responsive Layouts)
* **Backend Structure:** Node.js API architecture
* **Deployment:** Vercel (Cloud Hosting) & GitHub (Version Control)

## 🚀 Local Setup
If you'd like to run this project locally:
1. Clone the repository.
2. Install dependencies: `pnpm install`
3. Start the dev server: `npx vite`
